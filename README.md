## Как проходит публикация

`Правка в GitHub` → `Commit в main` → `Автодеплой Timeweb` → `Обновление kulmyakov.ru`

Для обычной текстовой правки не нужно заходить в Timeweb. Он требуется только для проверки статуса деплоя, домена, SSL и расходов.

## Как устроен сайт

- `index.html` — все тексты и восемь содержательных блоков страницы.
- `styles.css` — цвета, размеры, сетки и мобильная версия.
- `portrait.png` — портрет на первом экране.
- `README.md` — эта инструкция.

Timeweb автоматически публикует изменения после каждого сохранения в ветку `main`.

## Как изменить текст через GitHub

1. Откройте `index.html` в репозитории.
2. Нажмите значок карандаша `Edit this file`.
3. Найдите нужную фразу через `Cmd + F`.
4. Измените только видимый текст, не удаляя конструкции в угловых скобках `<...>`.
5. Нажмите `Commit changes`.
6. Выберите `Commit directly to the main branch` и подтвердите изменение.

После этого Timeweb запустит автоматический деплой. Обновление сайта обычно занимает несколько минут.

## Как найти нужный блок

В `index.html` каждый раздел отмечен комментарием:

- `БЛОК 1` — первый экран;
- `БЛОК 2` — обо мне;
- `БЛОК 3` — чем занимаюсь;
- `БЛОК 4` — что получает бизнес;
- `БЛОК 5` — интересные задачи;
- `БЛОК 6` — профиль;
- `БЛОК 7` — о чём думаю;
- `БЛОК 8` — контакты.

Комментарии выглядят как `<!-- БЛОК ... -->` и не отображаются посетителям сайта.

## Как изменить порядок блоков

Каждый блок начинается тегом `<section ...>` и заканчивается тегом `</section>`. Чтобы переставить раздел, переносите целиком весь фрагмент от открывающего до закрывающего тега вместе с комментарием `БЛОК`.

Перед такой правкой лучше сохранить копию текста или использовать Visual Studio Code, где границы блоков видны лучше.

## Как заменить фотографию

1. Подготовьте PNG-файл с прозрачным фоном.
2. Назовите его `portrait.png`.
3. Загрузите в корень репозитория через `Add file` → `Upload files`.
4. Подтвердите замену существующего файла и сохраните изменение.

## Как изменить оформление

Откройте `styles.css`. В начале файла находится раздел `ЦВЕТА И ОСНОВНЫЕ ПАРАМЕТРЫ САЙТА`.

Основные значения:

- `--bg` — фон страницы;
- `--paper` — фон светлых карточек;
- `--ink` — основной тёмный цвет;
- `--muted` — второстепенный текст;
- `--accent` — основной акцент;
- `--warm` — дополнительный золотистый акцент;
- `--max` — максимальная ширина содержимого.

Остальные правила сгруппированы по тем же номерам блоков, что и в `index.html`.

## Как отменить неудачное изменение

1. На странице репозитория откройте историю `Commits`.
2. Найдите последнюю рабочую версию.
3. Откройте неудачный коммит и выберите `Revert`.
4. Подтвердите создание обратного изменения.

Не удаляйте репозиторий, ветку `main`, файлы `index.html` и `styles.css`: они нужны для автоматической публикации.

## Если сайт не обновился

1. Подождите несколько минут и обновите страницу без кэша: `Cmd + Shift + R`.
2. Откройте Timeweb Cloud → `App Platform` → `kulmyakov-site` → `Деплой`.
3. Убедитесь, что последний деплой отмечен зелёным статусом `Успешно`.
4. Сверьте короткий номер коммита в Timeweb с последним коммитом в GitHub.
5. Если деплой завершился ошибкой, откройте его лог и найдите первую строку с `ERROR`.
